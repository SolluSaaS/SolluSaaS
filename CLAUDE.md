# Instruções para qualquer IA neste repositório

Fale com o Nunes em português do Brasil.

## Decisões e regras moram no AppGuide

Este repositório **não guarda** decisão nem regra de projeto (Nunes, 16/11/2026: «As regras têm que ser escritas, não lembradas»; AppGuide REGRAS §56).

- **Biblioteca de decisões:** `SolluSaaS/AppGuide › projetos/INDICE.md` é a lista curta dos projetos. Este repositório abre a estante **sollusaas**: `projetos/sollusaas/decisoes-fechadas.md`. Vale também a estante `projetos/todos/`.
- **Regras:** `SolluSaaS/AppGuide › v3/kit/docs/appguide/REGRAS.md` (índice curto; o texto de cada regra está no arquivo que a linha aponta).
- **Antes de recomendar, decidir ou criticar** ferramenta, fornecedor, plano, risco, arquitetura ou processo, leia o índice e a estante. Decisão fechada não se reabre; só o Nunes muda uma decisão.
- **Decisão nova do Nunes** entra no AppGuide, na estante do projeto, no mesmo turno em que ele decide. Não a escreva aqui.
- Sem o AppGuide aberto na conversa, peça para abrir; não decida de memória.
